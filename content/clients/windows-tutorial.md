许多初次在 Windows 笔记本或台式机上使用机场的朋友，往往会遇到“软件打开了但网页打不开”、“微信能上但浏览器搜不了外网”等困扰。

本文专门讲解 Windows 系统环境下运行好机场的核心原理与设置要点。

## 一、理解 Windows 的“系统代理”

在 Windows 下，代理客户端（如 Clash Verge Rev 或 v2rayN）通常通过修改系统的 Internet 选项来发挥作用：
- 当你在软件中开启 **“系统代理”** 时，Windows 会自动把 Edge、Chrome 等浏览器的网络流量路由到客户端本地监听端口；
- **核心原则：日常用完想完全关闭代理时，必须在软件内关闭系统代理开关，然后再退出软件。** 如果直接暴力结束进程，可能会导致系统代理残留，出现“电脑突然断网连百度都打不开”的尴尬情况。

## 二、设置“规则分流”（智能分流）

好机场的客户端通常默认采用**规则模式（Rule）**：
- **访问国内网站（百度、淘宝、B站等）：** 流量直接走本地宽带直连，不消耗机场配额，速度最快；
- **访问海外受阻网站（Google、GitHub等）：** 流量自动走选定的好机场节点；
- 小白切记：不要盲目选择“全局模式（Global）”，全局模式会导致国内应用也走海外节点，既卡顿又白白耗费机场流量。

## 三、推荐设置：开机自启动与静默运行

为了省去每次开机手动打开软件的繁琐：
1. 在 Clash Verge Rev 的“设置”中，勾选 **“开机自启 (Auto Launch)”**；
2. 勾选 **“静默启动 (Silent Start)”**；
3. 勾选 **“系统代理自动开启”**；
4. 这样每次启动电脑，好机场就会在后台静默护航，上网体验毫无割裂感。
