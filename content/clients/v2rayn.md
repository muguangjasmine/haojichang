如果你使用的是轻薄办公本，或者不喜欢带花哨图形界面的应用，那么经典的 **v2rayN** 绝对是你的首选。作为 Windows 平台上历史悠久、资源占用极低的开源客户端，它以稳定、纯粹和对核心底层协议的高度兼容而著称。

下面带大家一步步完成 v2rayN 与好机场订阅的对接。

## 一、下载解压与组件准备

1. 从官方 GitHub 仓库下载最新的 `v2rayN-with-Core.zip`（一定要下载带 Core 内核的完整压缩包）；
2. 将压缩包解压到一个固定的英文文件夹下（例如 `D:\Tools\v2rayN`），切勿直接在压缩包内双击运行；
3. 双击运行 `v2rayN.exe`，系统托盘右下角会出现一个小蓝色“V”图标。

## 二、添加机场订阅链接

1. 在好机场后台复制通用的 V2Ray 或标准订阅链接；
2. 打开 v2rayN 主界面，点击顶部菜单的 **“订阅分组”** -> **“订阅分组设置”**；
3. 在弹出的窗口中点击 **“添加”**；
4. 备注填入你的机场名字（如“梯子云”），在 **“可选地址 (Url)”** 框中粘贴刚才复制的订阅链接；
5. 点击底部的 **“确定”** 保存。

## 三、更新并测试节点

1. 回到主界面，点击顶部菜单的 **“订阅分组”** -> **“更新全部订阅 (不通过代理)”**；
2. 窗口下方会弹出一串日志，列表里瞬间刷出所有的节点名称；
3. 按键盘 `Ctrl + A` 全选所有节点，单击鼠标右键选择 **“测试服务器真实延迟 (Ctrl+R)”**；
4. 稍等片刻，排在最前面显示绿色的几百毫秒真实连接节点，就是当前最佳节点。选中其中一个按回车键激活。

## 四、开启系统代理与路由模式

1. 看向 v2rayN 窗口底部状态栏：
   - **系统代理：** 点击下拉框选择 **“自动配置系统代理”**（托盘V图标会变成红色，代表代理生效）；
   - **路由模式：** 点击下拉框选择 **“绕过大陆 (Whitelist)”**；
2. 此时打开浏览器，访问测试网页即可畅享海外网络。
