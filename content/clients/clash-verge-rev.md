在原版 Clash for Windows 停止维护之后，**Clash Verge Rev** 凭借其现代优雅的界面、活跃的开源社区支持以及原生集成的强大内核，迅速成为 Windows 和 macOS 上最受推崇的新一代代理客户端。

很多第一次买好机场的新手不知道如何配置。本文用大白话步骤，带你从零搞定。

## 一、准备工作与下载安装

1. **认准官方开源发布页：** 从 GitHub 的官方发布仓库或机场后台推荐的链接下载最新安装包（Windows 用户通常下载扩展名为 `.exe` 的安装程序）。
2. **正常安装：** 双击运行安装程序，一路点击“下一步”完成安装，桌面上会出现一个蓝色的小猫咪图标。

## 二、获取好机场的订阅链接

1. 打开你购买的好机场官网，登录用户中心后台；
2. 找到“仪表盘”或“用户首页”；
3. 寻找带有 **“一键导入 Clash”** 或 **“复制 Clash 订阅链接”** 的按钮；
4. 点击“复制”，此时订阅链接已经保存在你的电脑剪贴板中。

## 三、导入订阅与下载节点列表

1. 打开 Clash Verge Rev 客户端；
2. 在左侧菜单栏中点击 **“订阅 (Profiles)”**；
3. 在顶部的输入框中，按 `Ctrl + V` 粘贴刚才复制的机场订阅链接；
4. 点击右侧的 **“保存 (Save)”** 或 **“下载”** 按钮；
5. 稍等两三秒，界面上就会出现一个崭新的订阅卡片，并显示节点下载成功。鼠标左键点击该卡片，确保其被选中激活。

## 四、选择节点并开启系统代理

1. 点击左侧菜单栏的 **“代理 (Proxies)”** 页面；
2. 此时你会看到“节点选择”分组，下方列出了该机场提供的所有香港、日本、新加坡等节点；
3. 点击右下角的小闪电图标进行**延迟测试**，挑选一个延迟在 30ms—80ms 之间、显示为绿色的节点单击选中；
4. 点击左侧菜单栏的 **“设置 (Settings)”**；
5. 找到 **“系统代理 (System Proxy)”** 开关，将其向右滑动打开！
6. 此时打开浏览器访问 Google，即可发现已经能够秒开访问了！
